# Кулинарна Книга

Сайт за кулинарни рецепти

## Функционалности
- Добавяне на нова рецепта
- Редактиране на съществуваща рецепта
- Изтриване на рецепти(с екран за потвърждение)
- Детайли на рецепти(описание,време за приготвяне,категория)
- Описание какво представлява самото ястие
- Организация на рецептите по-категории
- Валидация на въведените данни(не позволява, запаметяване на рецепта без въведени определен брой символи)
- Регистрация и вход на потребители

## Технологии
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core 8 
- Microsoft SQL Server(LocalDb)
- ASP.NET Core Identity(регистрация и вход)
- Bootstrap  5
- jQuery Validation (клиентска валидация)

## Как да стартираме проекта
1. Инсталирайте Visual Studio 2022 с модула "ASP.NET and web development". Включва .NET 8 SDK и SQL Server LocalDB
2. Сваляне на кода: https://github.com/bonevlachezar/CookBook.git
3. Отваря се файла: CookBook_2026.sln
4. Създаването на базата: Package Manager Console -> Update-Database
5. Пускане на програмата: F5

## Настройки
- Връзка към база данни (файлът appsettings.json, ключ DefaultConnection)
- Няма създадени пароли и ключове  използва се LocalDB с Windows вход
- Не са нужни промени, за да тръгне, ако има LocalDB
